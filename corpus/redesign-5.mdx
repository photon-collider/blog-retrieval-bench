## New Font Stack

I'm using these fonts now:

- [**Space Grotesk**](https://fonts.google.com/specimen/Space+Grotesk). I love the techie and slightly quirky vibe of this font. Mainly using this in headers and some navigational elements.
- [**FK Roman Standard**](https://fonts.floriankarsten.com/fk-roman-standard). Having previously used [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) for body text in the past I wanted to try something new and fresh. I discovered this font from reading articles on [_The Verge_](https://www.theverge.com/) and it just so happens to be designed by Florian Karsten, the same designer of Space Grotesk. I like how legible and slightly elegant this font is.
- [**IBM Plex Mono**](https://fonts.google.com/specimen/IBM+Plex+Mono). This has been my go-to monospace font for sometime now. I mainly use this for code snippets, tags, and the byline in blog posts.

## Moving Away from TailwindCSS

[While I've good experiences working with TailwindCSS](/blog/simplifying-my-website-css-using-tailwind/), I no longer see it as a necessity for this project. Over the past year, I've grown more comfortable writing my own CSS especially since working through some exercises in [this short course on CSS layouts.](https://every-layout.dev) Removing TailwindCSS was relatively easy to do given that Astro components already support locally-scoped CSS styles in components.

I now have my CSS in a few different files:

- `base.css:` Base styles for the entire site, such as anti-aliasing and some CSS resets.
- `prose.css:` Styles for prose content in blog posts, focusing mostly on typography.
- `fonts.css:` Font-face declarations.
- `tokens.css:` CSS variables for colors, spacing, and typography scales (generated using [utopia.fyi](https://utopia.fyi/)).
- `cube.css:` Styles based on the [CUBE CSS approach.](https://cube.fyi/)
- `utilities.css:` Miscellaneous reusable helper classes.

I first encountered CUBE CSS in [this CSS course by Andy Bell](https://piccalil.li/complete-css/). I'm still learning the ins and outs of how to best use this in my current project.
